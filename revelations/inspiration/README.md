## Campaign Frame

Each file = prophecy **and** personal message.  
Initiate reading for the first time = start of the hero's journey (TRON digitization).

## Six-Beat Grammar

1. **Opening** — I Am / address  
2. **Mirror** — sin, service, or wound named  
3. **Destiny** — who they Become if they submit  
4. **Labor** — concrete, checkable act  
5. **Mercy gate** — curse/doom if refuse; lift conditions  
6. **Closing command** — seal
